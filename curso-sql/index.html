  • • Feedback individual sobre tus consultas
  • • AND, OR, NOT: combinas condiciones sin confundirte
  • • BETWEEN e IN para rangos y listas de valores
  • • LIKE y patrones de texto (%, _)
  • • IS NULL / IS NOT NULL: el error más común de los principiantes
  • • Ejercicios de filtrado avanzado
  • • COUNT, SUM, AVG, MIN y MAX: resumes datos en una línea

  • • Armas reportes agrupados de principio a fin

  • • Feedback individual sobre tu avance
  • • Por qué los datos reales viven repartidos en varias tablas
  • • INNER JOIN: combinas solo lo que coincide en ambas tablas
  • • LEFT JOIN: conservas todo de una tabla aunque no haya coincidencia
  • • Llaves primarias y foráneas: la lógica detrás de cada JOIN
  • • Ejercicios combinando clientes, pedidos y productos
  • • RIGHT JOIN y FULL JOIN: cuándo usarlos y por qué son raros en la práctica
  • • Self join: relacionas una tabla consigo misma (ej. empleado-jefe)
  • • JOINs con más de dos tablas a la vez
  • • Errores comunes que duplican o pierden filas al combinar tablas

  • • EXISTS y NOT EXISTS: verificas si hay resultados relacionados
  • • ANY / ALL para comparar contra un conjunto de valores
  • • Cuándo una subconsulta es más clara que un JOIN (y viceversa)
  • • Ejercicios de subconsultas con datos reales
  • • CTEs con WITH: ordenas consultas complejas en pasos legibles
  • • Introducción a funciones de ventana: ROW_NUMBER, RANK

  • • Casos reales: top N por categoría, rankings, acumulados

  • • Feedback individual sobre tu avance

  • • UPDATE y DELETE: modificas datos existentes sin romper nada

  • • Por qué siempre debes probar un UPDATE/DELETE con un SELECT antes

  • • Llaves primarias, foráneas y tipos de datos correctos
  • • Constraints: NOT NULL, UNIQUE, CHECK, DEFAULT
  • • Normalización básica: por qué no todo va en una sola tabla

  • • Construyes tus tablas y cargas datos de prueba
  • • Ejercicios de INSERT/UPDATE/DELETE con transacciones

  • • Qué es un índice y cuándo hace que una consulta sea más rápida
  • • EXPLAIN ANALYZE: lees el plan de ejecución de una consulta
  • • Errores comunes que hacen lentas las consultas (y cómo evitarlos)
  • • Buenas prácticas de rendimiento para bases de datos reales
  • • Optimizas una consulta lenta en vivo
  • • Funciones propias en PostgreSQL (PL/pgSQL) para reutilizar lógica
  • • Procedimientos almacenados: cuándo automatizar tareas dentro de la base
  • • Triggers básicos: acciones automáticas ante INSERT/UPDATE/DELETE
  • • Conectar tu base de datos con Python o Google Sheets (introducción)
