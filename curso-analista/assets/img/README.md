# Imágenes requeridas

Coloca en esta carpeta las siguientes imágenes antes de publicar (referenciadas en `index.html`):

| Archivo esperado          | Dónde se usa                          | Recomendación                              |
|----------------------------|----------------------------------------|---------------------------------------------|
| `og-image.jpg`              | Meta tags Open Graph (vista previa al compartir en WhatsApp/redes) | 1200x630px, con el nombre del curso y precio |
| `instructor.jpg`            | Sección "Sobre el instructor"          | Foto profesional, fondo neutro, cuadrada     |
| `favicon.png`               | Favicon del sitio (raíz de `/curso/`)  | 512x512px, ícono simple reconocible          |
| `hero-bg.jpg` (opcional)     | Fondo decorativo del Hero              | Imagen relacionada a datos/dashboards        |

Mientras no agregues las imágenes reales, el sitio funciona igual: se muestran
iniciales/íconos de reemplazo (placeholders) para que nada se rompa visualmente.
