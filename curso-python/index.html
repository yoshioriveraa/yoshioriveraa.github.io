Plan de estudios

Temario completo · 10 clases (20 horas)

Sábados y domingos, 7:00 pm a 9:00 pm (hora Perú) · Del 5 de septiembre al 4 de octubre

Objetivo: que escribas y ejecutes código el mismo día 1.

  • • Qué es Python, para qué sirve y panorama de librerías (Pandas, NumPy, Matplotlib/Seaborn)
  • • Tour rápido de Google Colab: celdas de código y texto, Shift + Enter, guardar en Google Drive
  • • Tu primer programa: print() y comentarios
  • • Tipos de datos básicos: int, float, str, bool
  • • Variables: creación, asignación y buenas prácticas de nombres
  • • Operadores aritméticos: + - * / // % **

Práctica en vivo

  • ▸ Programa que imprime tus datos personales
  • ▸ Calculadora simple con valores fijos
  • ▸ Cálculo del área de un rectángulo

Objetivo: dominar el manejo de datos simples y comparaciones lógicas.

  • • Conversión de tipos: int(), float(), str()
  • • input() para capturar datos del usuario
  • • Operadores relacionales: == != > < >= <=
  • • Operadores lógicos: and, or, not
  • • Strings: concatenación, f-strings y métodos básicos (.upper(), .lower(), .strip(), len())

Práctica en vivo

  • ▸ Calculadora de IMC interactiva con input()
  • ▸ Comparador de dos números
  • ▸ Formateo de texto combinando variables con f-strings

Objetivo: que tu programa tome decisiones y repita tareas.

  • • if, elif, else: condiciones anidadas y combinadas con and/or
  • • Bucle for con range()
  • • Bucle while
  • • break y continue
  • • Combinar condicionales dentro de bucles (el patrón que después usarás todo el tiempo en Pandas)

Práctica en vivo

  • ▸ Sistema de clasificación de notas (aprobado / desaprobado / mención)
  • ▸ Calculadora de descuentos según monto de compra (caso de negocio)
  • ▸ Tabla de multiplicar generada con for
  • ▸ Contador de productos que cumplen una condición (ej. precio > 50) recorriendo una lista

Objetivo: dominar las estructuras de datos que son la base directa de Pandas.

  • • Listas: creación, indexación, slicing y métodos (.append(), .remove(), .sort(), .pop())
  • • Tuplas: qué son, en qué se diferencian de las listas y cuándo usarlas
  • • Diccionarios: clave/valor, .keys(), .values(), .items() y actualización
  • • Listas anidadas y listas de diccionarios: la estructura idéntica a una tabla — puente directo a Pandas
  • • List comprehension (nivel básico)
  • • Funciones básicas: def, parámetros y return

Práctica en vivo

  • ▸ Inventario de tienda como lista de diccionarios: agregar, eliminar y actualizar stock
  • ▸ Base de clientes simulada (nombre, edad, compra)
  • ▸ Integrador: calcular totales, máximos y promedios "a mano", sin Pandas — la fricción que justifica la clase 5

Objetivo: dar el salto de las estructuras nativas de Python a herramientas reales de análisis.

  • • NumPy: arrays, diferencia con listas, operaciones vectorizadas e indexación básica
  • • Pandas: Series y DataFrame
  • • Crear un DataFrame desde un diccionario o una lista (conexión directa con la clase 4)
  • • Subir y leer un CSV en Colab: files.upload() o desde Google Drive, y luego pd.read_csv()
  • • Exploración: .head(), .tail(), .info(), .describe(), .shape, .columns, .dtypes
  • • Identificación de valores nulos: .isnull() y .sum()

Práctica en vivo

  • ▸ Cargar en Colab el CSV de ventas de una tienda/minimarket
  • ▸ Explorar su estructura, tipos de datos y calidad (nulos, duplicados)
  • ▸ Responder las primeras preguntas de negocio solo con exploración

Objetivo: transformar y filtrar datos como se hace en un análisis real.

  • • Selección de columnas y filas con loc e iloc
  • • Filtrado condicional: el equivalente en Pandas de los if de la clase 3, aplicado a columnas completas
  • • Filtros combinados con & y |
  • • Creación de nuevas columnas calculadas
  • • Ordenar datos con .sort_values()
  • • Renombrar columnas y cambiar tipos de datos con .astype()
  • • Manejo básico de nulos: .dropna() y .fillna()

Práctica en vivo

  • ▸ Filtrar productos por categoría y rango de precio
  • ▸ Crear la columna "precio con IGV" (18%) sobre el dataset real
  • ▸ Limpiar el dataset de ventas: nulos y tipos de datos incorrectos

Objetivo: agregaciones y cruces de datos — lo que realmente responde preguntas de negocio.

  • • .groupby() y funciones de agregación (.sum(), .mean(), .count(), .max(), .min())
  • • Múltiples agregaciones a la vez con .agg()
  • • Tablas dinámicas con .pivot_table()
  • • Combinar datasets: .merge() y .concat()
  • • .value_counts() para conteos rápidos

Práctica en vivo

  • ▸ Ventas totales por categoría y por mes con groupby()
  • ▸ Producto más vendido y ticket promedio
  • ▸ Cruzar la tabla de ventas con la de productos (simulando inventario + ventas)

Objetivo: convertir datos en gráficos que comuniquen algo, con tiempo suficiente para practicar cada tipo de gráfico.

  • • Matplotlib: plt.plot(), plt.bar(), plt.hist(), plt.scatter() y personalización (títulos, ejes, colores, tamaño de figura, subplots)
  • • Seaborn: sns.barplot(), sns.histplot(), sns.heatmap(), sns.lineplot(), sns.boxplot()
  • • Qué gráfico usar según el tipo de dato: categórico, numérico, tendencia en el tiempo o correlación
  • • Buenas prácticas de comunicación visual: títulos claros, no sobrecargar el gráfico y elegir la escala correcta

Práctica en vivo

  • ▸ Graficar ventas por categoría (barras) y tendencia mensual (líneas) sobre el dataset de la tienda
  • ▸ Heatmap de correlación entre variables numéricas
  • ▸ Comparar el mismo gráfico en Matplotlib vs. Seaborn para ver la diferencia de esfuerzo y resultado

Objetivo: aplicar todo el flujo de análisis de punta a punta, en una sesión completa y sin contenido nuevo de por medio.

  • • Repaso ultra rápido (10 min) del flujo completo: exploración → limpieza → filtrado → agregación → visualización
  • • Construyes tu propio notebook de análisis desde cero, sobre el dataset de ventas que venimos trabajando desde la clase 5
  • • Flujo guiado paso a paso, pero ejecutado por ti

Tu proyecto, paso a paso

  • ▸ Cargar y explorar el dataset (.info(), .describe(), nulos)
  • ▸ Limpiar: nulos, duplicados y tipos de datos
  • ▸ Filtrar según una pregunta de negocio que tú elijas (ej. "¿qué categoría genera más ingresos?")
  • ▸ Agrupar y calcular métricas con groupby y agg
  • ▸ Graficar 3 insights con Matplotlib/Seaborn
  • ▸ Redactar 2-3 conclusiones en una celda markdown de Colab, a modo de mini-reporte

Al tener su propia clase completa (2 horas sin contenido nuevo), este es el momento de dejar el notebook ordenado y presentable: es el que subirás a GitHub en la clase 10.

Objetivo: terminar el curso con un proyecto público y presentable, sin salir de Colab.

  • • Qué es Git y qué es GitHub, y en qué se diferencian (breve, sin teoría de más)
  • • Crear tu cuenta y tu primer repositorio en GitHub
  • • Subir un notebook directamente desde Colab: Archivo > Guardar una copia en GitHub — sin terminal y sin instalar nada
  • • Redactar un buen README.md en GitHub: qué hace el proyecto, qué dataset usa, qué insights encontraste y capturas de los gráficos
  • • Buenas prácticas: nombre de repositorio claro, descripción del proyecto y organización mínima de archivos

Práctica en vivo

  • ▸ Conectas tu cuenta de GitHub desde Colab y subes el notebook del proyecto final
  • ▸ Redactas tu propio README
  • ▸ Cierre del curso: cada estudiante comparte el link de su repositorio — tu portafolio inicial
